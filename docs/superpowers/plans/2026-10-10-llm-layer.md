# LLM Layer (No Vertex, Multi-Provider + Fallback) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace hard-coded `google-vertex:` models with a config-driven LLM layer (Anthropic / OpenAI / Gemini API key) with ordered provider fallback, and remove all Vertex/GCP code, env vars and dependencies.

**Architecture:** A new `hr_breaker/llm.py` turns a comma-separated `provider:model` chain string into a pydantic-ai `Model` (a single model, or a `FallbackModel` that falls through on transient errors only). `utils/retry.py` is made provider-neutral. Every agent calls `build_model(<chain string>)` instead of the `google-vertex:` f-string. Startup validates the chains and API keys.

**Tech Stack:** Python 3.13, pydantic-ai 1.48 (`FallbackModel`, `infer_model`), pytest + pytest-asyncio (`asyncio_mode = auto`), uv.

**Spec:** `docs/superpowers/specs/2026-10-10-llm-layer-design.md`

**Deviations from the spec (decided while planning, from reading the code):**
1. `build_model` takes the chain *string* (e.g. `settings.optimization_model`), not a role name. The auditor accepts a per-call model override, and a string keeps the factory free of config lookups.
2. Default chains are single-provider (Gemini only, no fallback). Putting `anthropic:` in the defaults would make boot fail for anyone who only has a Gemini key. The fallback chain is documented in `.env.example` as an opt-in example.
3. Added `MODEL_PROVIDER_TIMEOUT` (per-provider request timeout). The existing outer `MODEL_CALL_TIMEOUT` wraps the *whole* chain, so a hung primary would eat the entire timeout before any fallback is tried. The per-provider timeout makes a hung primary fail fast and fall through.
4. "Log which provider served each call" is reduced to logging each fallback hop at WARNING (done inside the fallback predicate). Logging the serving provider on success is skipped (YAGNI).

## Global Constraints

- No Vertex/GCP code, env vars, or dependencies may remain (`vertexai`, `google-vertex`, `GOOGLE_CLOUD_*`, `GOOGLE_APPLICATION_CREDENTIALS*`, `google-cloud-aiplatform`).
- Supported providers: `google-gla` (key `GEMINI_API_KEY`), `anthropic` (key `ANTHROPIC_API_KEY`), `openai` (key `OPENAI_API_KEY`).
- Chain format: comma-separated `provider:model` strings; one entry = no fallback.
- Fallback only on transient failures: HTTP 429, 500, 502, 503, 504, 529, connection errors, timeouts. 400/401 must not fall through.
- Concurrency cap stays global (`MODEL_MAX_CONCURRENCY`); no per-provider caps.
- Prompts are not changed.
- `GEMINI_THINKING_BUDGET` is removed.
- Python code must run on the project's venv (`uv run pytest ...`). Never commit `.env`.

## Review Focus

Failure modes the spec implies but a straightforward implementation would miss (each has a test in the named task):

1. Legacy unprefixed value `OPTIMIZATION_MODEL=gemini-2.5-flash` (what production has today) → clear error naming the expected `provider:model` format, not an obscure pydantic-ai error. (Task 2)
2. Chain with stray whitespace / trailing comma (`"a:x, b:y,"`) parses to two entries; an empty string is an error. (Task 2)
3. `google-vertex:` (or any unsupported provider) in a chain is rejected, so Vertex cannot sneak back through config. (Task 2)
4. Missing key for a *fallback-only* provider fails at startup and names the env var and the chain. (Task 2)
5. Primary returns 401/400 → no fallback, error surfaces; primary 429 → falls through to secondary. Whole chain failing is retried by `with_model_retry`. (Tasks 1, 2)
6. Hung primary: the per-provider timeout is set in model settings so it falls through instead of consuming the outer timeout. (Task 3)

```python
"""Retry helper for transient model-provider errors (429 / 5xx / connection / timeout)."""

import asyncio
import random
from collections.abc import Awaitable, Callable
from typing import TypeVar

from pydantic_ai.exceptions import FallbackExceptionGroup, ModelAPIError, ModelHTTPError

from hr_breaker.config import get_settings, logger

T = TypeVar("T")

# Rate limit / quota (429), server errors (500/502/503/504) and provider overload
# (529, Anthropic). 400/401/403/404 are caller errors: retrying or switching
# provider will not fix them.
_RETRYABLE_STATUS = (429, 500, 502, 503, 504, 529)

# Process-wide cap on concurrent model calls so parallel requests don't stampede
# provider quotas. Created lazily so tests / CLI don't need an event loop at
# import time.
_semaphore: asyncio.Semaphore | None = None


def _get_semaphore() -> asyncio.Semaphore:
    global _semaphore
    if _semaphore is None:
        _semaphore = asyncio.Semaphore(get_settings().model_max_concurrency)
    return _semaphore


def is_transient_error(exc: BaseException) -> bool:
    """True if retrying (or falling back to another provider) can plausibly help."""
    if isinstance(exc, FallbackExceptionGroup):
        return all(is_transient_error(e) for e in exc.exceptions)
    if isinstance(exc, ModelHTTPError):
        return exc.status_code in _RETRYABLE_STATUS
    if isinstance(exc, ModelAPIError):  # non-HTTP: connection reset, DNS, etc.
        return True
    return isinstance(exc, TimeoutError)


async def with_model_retry(
    operation: Callable[[], Awaitable[T]],
    *,
    label: str = "model call",
    max_attempts: int = 4,
    base_delay: float = 1.0,
    max_delay: float = 30.0,
    timeout: float | None = None,
) -> T:
    """Run ``operation`` (an async model call), retrying transient provider errors
    with full-jitter exponential backoff.

    Each attempt is bounded by ``timeout`` seconds (default from settings) so a
    stalled connection can't hang the caller indefinitely, and all calls share
    a process-wide concurrency semaphore. Timeouts are retried like transient
    errors; non-transient errors and the final attempt re-raise immediately.
    """
    if timeout is None:
        timeout = get_settings().model_call_timeout
    for attempt in range(1, max_attempts + 1):
        try:
            async with _get_semaphore():
                return await asyncio.wait_for(operation(), timeout=timeout)
        except TimeoutError:
            if attempt == max_attempts:
                raise
            logger.warning(
                f"{label}: timed out after {timeout:.0f}s "
                f"(attempt {attempt}/{max_attempts}); retrying"
            )
        except (ModelAPIError, FallbackExceptionGroup) as e:
            if not is_transient_error(e) or attempt == max_attempts:
                raise
            cap = min(base_delay * 2 ** (attempt - 1), max_delay)
            delay = random.uniform(0, cap)
            logger.warning(
                f"{label}: transient error {type(e).__name__} "
                f"(attempt {attempt}/{max_attempts}); retrying in {delay:.1f}s"
            )
            await asyncio.sleep(delay)
    raise AssertionError("unreachable")  # pragma: no cover
```

```python
"""Config-driven LLM model factory: `provider:model[,provider:model...]` chains."""

from collections.abc import Sequence

from pydantic_ai.models import Model, infer_model
from pydantic_ai.models.fallback import FallbackModel

from hr_breaker.config import get_settings, logger
from hr_breaker.utils.retry import is_transient_error

# Direct providers only. Each reads its key from this env var (pydantic-ai default).
PROVIDER_KEY_ENV = {
    "google-gla": "GEMINI_API_KEY",
    "anthropic": "ANTHROPIC_API_KEY",
    "openai": "OPENAI_API_KEY",
}


def parse_chain(value: str, *, env_var: str = "model") -> list[str]:
    """Split a comma-separated chain into trimmed `provider:model` entries."""
    entries = [e.strip() for e in value.split(",") if e.strip()]
    if not entries:
        raise ValueError(f"{env_var} is empty; expected provider:model[,provider:model...]")
    for entry in entries:
        provider, _, name = entry.partition(":")
        if not provider or not name:
            raise ValueError(
                f"{env_var}: {entry!r} must be in provider:model format, "
                f"e.g. google-gla:gemini-2.5-flash or anthropic:claude-sonnet-5-5"
            )
    return entries


def validate_chain(chain: Sequence[str], *, env_var: str = "model") -> None:
    """Fail fast on unsupported providers and missing API keys."""
    import os

    for entry in chain:
        provider = entry.partition(":")[0]
        key_var = PROVIDER_KEY_ENV.get(provider)
        if key_var is None:
            raise ValueError(
                f"{env_var}: unsupported provider {provider!r} in {entry!r}; "
                f"supported: {', '.join(PROVIDER_KEY_ENV)}"
            )
        if not os.getenv(key_var):
            raise ValueError(f"{env_var}: {key_var} is not set (needed for {entry!r})")


def _fallback_condition(exc: Exception) -> bool:
    transient = is_transient_error(exc)
    if transient:
        logger.warning(f"LLM provider failed ({type(exc).__name__}: {exc}); trying next in chain")
    return transient


def _fallback(models: Sequence[Model | str]) -> FallbackModel:
    return FallbackModel(*models, fallback_on=_fallback_condition)


def build_model(value: str, *, env_var: str = "model") -> Model:
    """Build a pydantic-ai model from a chain string.

    One entry returns that provider's model; several return a FallbackModel that
    moves to the next entry only on transient errors (429 / 5xx / connection).
    """
    chain = parse_chain(value, env_var=env_var)
    validate_chain(chain, env_var=env_var)
    if len(chain) == 1:
        return infer_model(chain[0])
    return _fallback(chain)


def validate_llm_config() -> None:
    """Validate every configured role chain. Called at API / CLI startup."""
    settings = get_settings()
    for env_var, value in (
        ("OPTIMIZATION_MODEL", settings.optimization_model),
        ("COACH_MODEL", settings.coach_model),
        ("NAME_EXTRACTOR_MODEL", settings.name_extractor_model),
    ):
        validate_chain(parse_chain(value, env_var=env_var), env_var=env_var)
```
